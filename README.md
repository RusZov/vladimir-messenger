# vladimir-messenger
Гибридный децентрализованный мессенджер с P2P-архитектурой. Работает как через интернет (включая Tor), так и полностью без него — по Bluetooth, Wi-Fi Direct и mesh-сети. Сквозное шифрование, отсутствие центральных серверов и регистрации. Сообщения хранятся только локально. Поддержка голосовых сообщений, файлов, геолокации и групповых чатов.
