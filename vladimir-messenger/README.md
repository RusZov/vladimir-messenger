# Владимир Мессенджер — Прототип

Защищённый гибридный P2P-мессенджер с поддержкой работы через Tor, локальную сеть и BLE.

## Структура проекта

```
vladimir-messenger/
├── app.py                 # Основной файл приложения (Flask + логика)
├── crypto_module.py       # Модуль шифрования (X25519 + ChaCha20-Poly1305)
├── p2p_transport.py       # P2P транспорт (Tor + UDP discovery + TCP)
├── ble_mesh.py            # BLE mesh-сеть (опционально)
├── requirements.txt       # Зависимости Python
├── templates/
│   └── index.html         # Веб-интерфейс
├── static/
│   └── style.css          # Стили веб-интерфейса
└── docs/
    ├── architecture.md    # Архитектура
    ├── offline-protocol.md # Протокол офлайн-работы
    └── security.md        # Безопасность
```

## Установка

### Требования
- Python 3.10+
- Tor (для работы через .onion)
- Bluetooth-адаптер (опционально, для BLE)

### Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 2: Установка Tor

**Ubuntu/Debian:**
```bash
sudo apt-get install tor
```

**macOS:**
```bash
brew install tor
```

**Windows:** Скачайте с https://www.torproject.org/download/

### Шаг 3: Запуск приложения

```bash
python app.py
```

Приложение запустится на `http://localhost:5000`

## Режимы работы

### 1. Интернет (Tor)
При наличии интернета приложение создаёт скрытый сервис `.onion` и обменивается сообщениями через сеть Tor.

### 2. Локальная сеть (LAN)
Без интернета используется UDP-широковещание (порт 5000) для обнаружения узлов в Wi-Fi сети. Сообщения передаются напрямую по TCP.

### 3. BLE Mesh (опционально)
При наличии Bluetooth-адаптера поддерживается связь на расстоянии до 10 метров с mesh-ретрансляцией через промежуточные узлы.

## Использование

1. Откройте `http://localhost:5000` в браузере
2. Скопируйте свой публичный ключ и обменяйтесь им с собеседником (через QR-код или вручную)
3. Добавьте контакт, указав его публичный ключ
4. Начните обмен сообщениями

## Индикатор режима

В главном меню отображается текущий режим:
- 🌐 **Интернет** — работа через Tor
- 📶 **LAN** — локальная сеть
- 🔵 **BLE-mesh** — Bluetooth mesh-сеть

## Безопасность

- Все сообщения шифруются сквозным шифрованием (X25519 + ChaCha20-Poly1305)
- Публичные ключи проверяются при первом соединении (TOFU — Trust On First Use)
- Файлы передаются напрямую по P2P-каналу без промежуточных серверов

## Ограничения прототипа

- Максимальный размер файла: 10 МБ
- Mesh-сообщения хранятся до 5 минут
- Групповые чаты реализованы как простая рассылка всем узлам
